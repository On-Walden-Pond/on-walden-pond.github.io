# onwaldenpond.github.io

Website for **On Walden Pond** — weddings & celebrations, Calhoun, GA.
Static HTML/CSS, no build step. Published with GitHub Pages.

## Structure
- `index.html` — the whole site (single page, anchored sections)
- `styles.css` — theme: pine `#2f4034`, cream `#f7f4ec`, gold `#b08d57`; Cormorant Garamond + Inter
- `images/` — (to create) real photography; search `TODO:` in `index.html` for swap points
